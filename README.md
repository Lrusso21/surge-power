# Surge Power — Website Concepts

Two standalone, browser-ready website concept demos for Surge Power LLC:

- `surge-power-demo.html` — customer estimate-assistant experience
- `surge-power-owner-dashboard.html` — owner dashboard concept

## Viewing locally

Open either HTML file in a modern web browser. No installation, build process, API keys, or environment configuration is required.

## Repository hygiene

The repository intentionally excludes local working files, generated build output, dependencies, environment files, credentials, and logs via `.gitignore`.

## Note

These are independent concept demos and are not connected to a production backend.
